# Portal access
Deploy dist to enable the wrong-portal message and correct workspace link. The portal-access migration and elan-api version 13 are installed on the linked Élan project.
Verified staff administrators use /admin. Department members, heads, leadership seats and verified pending OC appointments use /organisers. Applicants use /application-status until appointed. Other verified accounts use /portal/login.html for the participant workspace. Admin status takes precedence even when the account also has an OC assignment. Shared password setup is available for onboarding and takes the user to the correct workspace afterward.
An existing participant with a matching OC application can explicitly move their login to recruitment. Merely submitting an application in someone else's name does not take an existing participant's portal away. Unverified or unresolved accounts cannot open protected workspace data.
Social Media → Department tools has the post calendar, platform, owner, planned date, copy, creative direction, references and evidence. The head coordinates the team's tasks and can propose briefings; members manage their own tasks and entries. Actual publishing on social platforms is manual.
Validation: 61 automated tests plus rollback database checks across all four roles, including an administrator with an OC assignment. Check signed-in production navigation after uploading dist.
