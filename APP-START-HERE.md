# Élan app delivery — 19 November 2026

This package retains the complete website and adds an installable web app plus Android and iPhone **hybrid app projects**. It is source code and bundled assets, not a signed APK, AAB or IPA. Store publication and device acceptance tests are still required.

## Ready in this package

- An app home at `/app.html`, with existing-account sign-in and server-selected participant, applicant, organiser or admin workspace.
- Installable PWA manifest, existing Élan icons, install instructions and supported-browser install button.
- A generic offline screen. No account pages, application responses, receipts, uploads or API responses are saved in service-worker caches. No offline writes or automatic replay of failed actions.
- Updates wait until open Élan windows close, so forms are not interrupted.
- All existing departmental, HR and leadership workspaces, reviews, interviews and permissions are reused.
- Bundled Capacitor Android and iOS projects; app navigation, Android back handling, native sharing and CSV/blob export sharing.
- Existing brand icons and splash screens, Android backups disabled, iOS required file-timestamp API declaration.
- Existing website remains the public event website. Its footer links to the app installation page.

## Website / installable app

Upload this project using your existing GitHub deployment process. The website output is still `dist/`; do not point web hosting at `mobile/www`, `android` or `ios`.

After deployment open `https://elansummit.com/app.html`. Android browsers with install support offer Install Élan; otherwise use the browser's install menu. On iPhone use Safari → Share → Add to Home Screen. The install button only appears when the browser offers an install prompt.

This package has not been uploaded to your GitHub repository or public website in this session. The new PWA becomes available after that deployment. HTTPS is required for its service worker.

## Android and iPhone projects

Prerequisites: Node 22 or later, Python 3 and the existing website build's Python dependencies. The Android project needs Android Studio/SDK 36 and JDK 21; iOS needs a Mac with the Xcode version supported by Capacitor 8. See https://capacitorjs.com/docs/getting-started/environment-setup for current requirements.

From the project directory:

```sh
npm ci
npm run check
npm run mobile:sync
```

For Android: `npm run mobile:android`, select a device/emulator in Android Studio, then run. For iPhone: `npm run mobile:ios`, choose your Apple signing team and device, then run. Capacitor uses Swift Package Manager for this iOS project.

App identifier: `com.elansummit.app`. Confirm this identifier in your developer accounts before publishing. App name: Élan Summit. Existing website users keep their accounts. No database copy or account migration is introduced.

`mobile/www`, Android's `assets/public` and iOS's `public` folder are generated by `mobile:sync`. They are included here for completeness. Make future interface changes in `src/` and native-specific changes in `mobile/`, then sync again.

## Account setup and external pages

People sign into the app using their existing email/password. The app checks `elan_login_portal`; it does not let users select or grant their own role. Existing server permissions still govern data access.

Account creation, invitation setup and password reset links continue to open the secure website in the browser. After completing setup, return to the app and sign in. Native universal links and automatic email-to-app session transfer are not implemented in this release.

Public application/enquiry/registration pages open in the browser so the existing CAPTCHA and email setup flow remain in their supported web environment. Application tracking, reviews and departmental work stay in the bundled app. External links open through the system browser. No push notifications are claimed or configured; existing automatic emails continue through the existing backend.

Existing Supabase session behaviour is retained; this release does not claim reliable OS force-close logout. Device testing must include account switching, background/foreground behaviour and sign-out. Do not share an already-signed-in device with another role.

## One production change still pending

The packaged API source adds **only** `capacitor://elansummit.com` to `elan-api`'s existing allowed-origin list, for iOS requests. Android uses the already-allowed `https://elansummit.com` origin. Authentication, roles, business logic and SQL are unchanged.

Automatic approval review blocked deploying the production Edge Function. The live API was **not changed**. `mobile/ios-origin.patch` shows the exact edit. Approval is needed before replacing the live function. Until it is applied, iPhone actions that call `elan-api` may fail CORS checks even when database reads/sign-in work. Do not distribute this iPhone build yet.

No new SQL migration is needed for this app package. Do not rerun old SQL files just to install the apps.
