ÉLAN SUMMIT | GITHUB AND CLOUDFLARE

Extract the ZIP. Open the inner Elan-GitHub-Deployment folder. The existing repository has scripts/build.py and dist/index.html, not a root index.html. Keep that layout.

For the source-build setup: copy the contents of Elan-GitHub-Deployment to the repository root, preserving the folders (src, scripts, dist and the other project files). Replace matching files. Do not flatten dist into the root, upload the ZIP itself, or nest the whole project inside another folder. Keep repository settings, .git and unrelated files.

Check the Cloudflare Pages project settings: if it runs python3 scripts/build.py, the output directory should be dist. If it publishes prebuilt files from dist without building, keep dist in that same location. Confirm a preview deployment works before merging. The production project settings are not verified by this package.

Supabase changes from previous releases are already installed. Do not run fresh-project.sql on an existing project. See docs/APPLICANT-PORTAL.md for the Auth dashboard settings and docs/HANDOUT.md for the invitation pilot. Do not commit private keys or passwords.

After deployment: check About Élan on mobile and desktop; submit a test application with an inbox you control; use the newest setup email and verify the role and destination. Closing a browser window is not a guaranteed logout. Use Sign out on shared devices.
